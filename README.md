# PURA Elite Cleaning website

SEO-focused static website for PURA Elite Cleaning.

## Included
- Responsive homepage with quote estimator
- Current PURA core price tables used by the estimator
- $25 half-bath and $40 additional-full-bath rules
- Fixed and scope-based add-ons
- Local landing pages for Lake Wylie, Fort Mill, Tega Cay, Ballantyne, SouthPark, Weddington/Marvin, Waxhaw, and Huntersville
- Service pages for deep cleaning, recurring cleaning, and move-in/move-out cleaning
- Organization/Service structured data
- Canonicals, metadata, sitemap.xml, robots.txt, and internal linking

## Deployment
Ready for a static host such as Vercel, Netlify, or GitHub Pages. Do not point puraelitecleaning.com here until a deployment preview has been tested.

## SEO note
No search-engine position is guaranteed. Local visibility depends on relevance, distance, prominence, reviews/citations, crawlability, content quality, and competition.
