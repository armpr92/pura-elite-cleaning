# PURA Elite Cleaning website

Production website for PURA Elite Cleaning.

## Design
- Black, white, and chrome-silver visual system
- Photo-backed hero using a locally stored site asset
- Multi-page structure with dedicated pages for Reviews, Charlotte Area, Lake Wylie, Rock Hill, and Huntersville
- No public customer pricing
- Quote request flow sends home details for PURA to review and call back

## SEO
Dedicated local pages, canonical URLs, structured service content, robots.txt, and sitemap.xml are included.

## Deployment
Production is hosted on Vercel at https://puraelitecleaning.com.
